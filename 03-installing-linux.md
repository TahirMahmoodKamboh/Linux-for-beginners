## 🧠 Ways to Install Linux

There are **three common ways** to install Linux:

1️⃣ Using a **Virtual Machine** (Recommended)  
2️⃣ Dual Boot (Linux + Windows)  
3️⃣ Full Linux Installation (Advanced)

---

## 🟢 Method 1: Virtual Machine (Recommended)

A **Virtual Machine (VM)** allows you to run Linux **inside** another operating system.

Examples of VM software:
- VirtualBox
- VMware

### ✅ Advantages
- Safe
- No data loss
- Easy to delete
- Best for beginners

### ❌ Disadvantages
- Slightly slower than real installation

📌 **Best choice for learning Linux**

---

## 🟡 Method 2: Dual Boot

Dual boot means:
- Linux and Windows installed on same computer
- Choose OS at startup

### ✅ Advantages
- Full hardware performance
- Real Linux experience

### ❌ Disadvantages
- Risky for beginners
- Disk partitioning required
- Possible data loss if done incorrectly

⚠️ **Not recommended for absolute beginners**

---

## 🔴 Method 3: Full Linux Installation

- Linux replaces Windows completely
- No Windows available

📌 Used by advanced users and servers

---

## 💿 What Is an ISO File?

An **ISO file** is:
- An image of an operating system
- Used to install Linux

Example:
- `ubuntu-22.04.iso`

---

## 🖥 Recommended Linux for Installation

For beginners:
✅ **Ubuntu LTS (Long Term Support)**

Why?
- Stable
- Large community
- Easy to use
- Lots of tutorials

---

## 🛠 Installing Linux Using VirtualBox (High-Level Steps)

1. Download Ubuntu ISO
2. Install VirtualBox
3. Create a new virtual machine
4. Attach Ubuntu ISO
5. Start VM and install Ubuntu
6. Login and start learning
